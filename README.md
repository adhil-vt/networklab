# Computer Networks Lab (CN LAB)

This repository contains lab experiments, programs, and algorithm documentation for Computer Networks.

## Contents

- **FTP**: File Transfer Protocol client-server implementation and algorithms
- **Leaky**: Leaky Bucket congestion control algorithm implementation and documentation
- **Sliding window**: Sliding Window Protocol sender and receiver implementation and documentation
- **Socket**: Basic Socket Programming client and server implementation
- **TCP**: Two-way TCP Chat client and server implementation
- **UDP**: UDP Chat client and server implementation
